# 需求暂存站 v2.3.4

## 新增功能

- 新增「紧急」消息标记：未归档消息右键 / 长按菜单首位提供「紧急 / 取消紧急」，不影响原有置顶 / 置底状态。
- 紧急消息在暂存列表中独立分为「紧急」分组，排在置顶之前，卡片带红色边框、红竖条和红色「紧急」标识。
- 桌面端启动时若存在未归档紧急消息，自动临时开启窗口置顶且不覆盖用户持久化置顶偏好。
- 归档（含批量归档与 Android 桌面小组件归档）自动清除紧急状态，恢复归档后不会重新变为紧急。

## 修复与改进

- 修复启动紧急临时置顶在修改排序等其他设置后被意外取消，以及与挂载期 `isAlwaysOnTop()` 竞态的问题。
- 修正紧急状态更新失败时的提示标题为「紧急状态更新失败」。
- 修复暂存列表相邻合并（向上 / 向下合并）按视觉顺序（紧急 → 置顶 → 普通 → 置底）查找邻居。
- Android 桌面小组件同步按紧急、置顶优先级排序，且归档时安全清零 `urgent`（兼容未补列的旧库）；调整紧急 / 置顶状态后主动刷新小组件。
- 精简设置页顶部文案与内边距。
- CI 的 Android 云端构建流程补充版本号同步步骤，与 Windows 构建保持一致。

## 安装包

- Windows：提供 EXE 安装包和 MSI 备用安装包。
- Android：提供正式签名通用 APK，可覆盖安装已有正式版本。
