# 需求暂存站 v2.3.3

## 界面与阅读

- 更新首页、搜索、分类、编辑器和设置页的浅色界面，收紧留白和正文行距。
- “普通”分类更名为“暂存”，分类名称加粗，保留消息数量显示。
- 置顶和置底消息分别分组，其余消息按日期分组。
- 新增桌面文本悬浮预览，采用小尺寸竖版纸页布局，支持长文本换行和分页阅读。
- 编辑器的正文、图片附件和底部操作区分开布局；附件直接排列，减少嵌套边框。
- 设置项直接排列在弹窗中，用分割线区分，保留数据导入、导出及迁移入口。

## 交互细节

- 统一按钮悬停与按下反馈：底色变化和内描边，取消外阴影。
- 归档、导入、编辑按钮分别使用灰底、蓝底、白底浅灰描边。
- 桌面列表、设置和编辑器等滚动区域使用悬浮滚动条，不挤占内容宽度；正文滚动条靠弹窗边缘显示。
- 操作提示放在首页底栏内，关闭图标统一为居中的矢量图标。

## Android

- 优化键盘弹出时编辑器与可见视口的适配。
- 修正小组件背景透明度显示，避免系统默认底板影响观感。

## 安装包

- Windows：提供 EXE 安装包和 MSI 备用安装包。
- Android：提供正式签名通用 APK，可覆盖安装已有正式版本。

## 验证

- 前端：185 项通过、9 项跳过。
- Rust：109 项通过、22 项忽略；格式检查通过。
